# 微信平台上线前行动清单

以下事项需要在微信公众平台、域名/云厂商和真实设备侧完成。仓库中的检查脚本只验证代码与配置 wiring，不代替平台审核。

1. 在「开发管理 → 开发设置」配置 `request` 合法域名为生产 API HTTPS 域名。
2. 配置 `uploadFile`、`downloadFile` 合法域名；若文件下载经 API 返回，也要把对应网关加入白名单。
3. 若启用 WebSocket，配置 `socket` 合法域名并确保使用 WSS 和有效证书。
4. API、上传和下载域名必须使用公网 HTTPS，证书链完整，不能使用 IP、localhost 或自签名证书。
5. 将真实 AppID 写入正式构建环境变量 `WECHAT_APP_ID`，AppSecret 仅保存在服务端密钥管理系统，不提交仓库。
6. 在「设置 → 隐私保护指引」声明聊天、资料上传、AI 生成和账号删除实际处理的信息；`wx.chooseMessageFile` 的文件信息用途必须与指引一致。
7. 提供并在小程序入口可访问：用户协议、隐私政策、数据处理说明、账号与资料删除说明。
8. 核验并完成适用的小程序备案/主体备案，材料和备案号以主管平台实际结果为准，不在代码中预填。
9. 在 AI 功能说明中列明实际使用的模型供应商/模型名称、生成内容用途、用户核验提示和投诉入口；不得填写虚构备案或登记号。
10. 所有 Chat、学习计划、测验、解析、简答评分和摘要页面保留 `AI 生成 · 请核验重要信息` 标识。
11. 配置内容安全审核供应商、违规输入/输出处置、举报受理和内部审核账号；验证审核日志不向普通用户开放。
12. 使用生产构建：设置 `WECHAT_API_BASE_URL`、`WECHAT_APP_ID` 后执行 `npm run build:wechat:production`，再把 `dist/wechat-production` 导入开发者工具。
13. 在开发者工具执行编译、预览和上传前检查，确认 `urlCheck=true`、Network 仅访问白名单 HTTPS/WSS 域名。
14. 使用体验版在 Android 与 iOS 真机验证登录、上传、Chat/Citation、学习计划、Quiz、断网/弱网、Token 失效、后台恢复、删除和隐私授权。
15. 上传体验版后，从版本管理提交审核；被拒时按「审核详情 → 拒绝原因 → 申诉/重新提审」入口逐项修正，并保留审核记录。
