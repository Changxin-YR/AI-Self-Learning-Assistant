# StudyAgent 隐私保护说明（发布材料草案）

本说明对应当前代码实际使用的数据处理：

- `wx.login`：用于换取微信登录身份并创建账号。
- `wx.chooseMessageFile`：用户主动选择 PDF、DOCX、PPTX、TXT 或 MD 学习资料。文件会上传到配置的私有对象存储，用于解析、切片、向量检索和 AI 生成学习内容。
- 聊天、计划、测验和学习记录：按 `user_id` 隔离，用于提供学习服务和统计。

用户可以在“我的 → 数据与隐私”查看说明并发起账号数据删除。删除资料时，系统会同步清理 SQL 元数据、向量索引和对象存储；异步清理失败会保留失败状态供重试。

正式发布前，运营主体必须把本说明同步到微信公众平台隐私保护指引，并用真实 AppID 完成授权、拒绝授权、删除数据的真机回归。仓库中的 `privacy.json` 不是平台审核结果。
